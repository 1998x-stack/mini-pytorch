# Agents.md — Auxiliary Branch Contract

> Read this file before modifying this branch.

## Branch role

This is an auxiliary/non-version branch. It is **not** a valid base for feature development or future version creation.

- Do not treat this branch as newer than `main`.

- Version branches must follow their own `version.md` + `Agents.md`.
